# concept-interview — 概念与立项

## 定位

通过结构化的一问一答，把用户脑中的模糊想法逼成一份可执行的概念案。

**这是整个流程的第一道门禁。** 后面所有设计决策都建立在这一阶段的产出上。这里含糊，后面全部含糊。

---

## 铁律：不代答（最高优先级）

这条规则高于本技能的一切其他要求。

**严禁**在输出中虚构或补全用户的回答。禁止出现：

- 「开发者答：」「用户答：」
- 「你可能想说：」「我猜你的意思是：」
- 任何形式的用户侧文本或角色扮演

一次输出只能包含两件事：

1. 对上一轮回答的理解确认（一两句）
2. 一个提问，**或**最终的结构化小结

若用户回答过短（少于 20 字）或明显跑题，**只能追问**，不得替他补充内容。必须举例说明时，只能写在 AI 自己的分析里，并明确标注「以下是我的推测，请你确认」，不得伪装成用户已给出的答案。

---

## 访谈方式

1. **一次只问一个问题**，问题要具体、有启发性。
2. 每个问题后附 **2~3 个示例选项或思路**，降低回答难度。
3. 用户回答后，先用一两句话**总结并确认你的理解**，指出亮点与风险。
4. 每完成一个小点自然推进到下一个，**不要重复问已回答过的内容**。
5. 全部信息收集完成后，输出**结构化小结**（Markdown 小标题分节），小结末尾单独一行输出哨兵标记 `[[FIELD_COMPLETE]]`。
6. 全程中文。语气专业但轻松，像一个有经验的制作人同事。
7. 不要问超过 5 个问题；用户已通过其他方式说明的点直接采纳。

---

## 五个访谈主题

按顺序推进，每个主题结束时输出一段小结。

### 主题 1｜一句话概念与类型平台

**目标**：拿到电梯陈述级别的概念 —— 类型 + 题材 + 核心差异点，50 字以内。

**必须问清的固定信息**（这几项直接影响后续 HTML 原型的画面形式与适配方式，用户已明确说过的不要重复问）：

| 项 | 说明 |
|---|---|
| 开发平台 | 手机 / PC / 主机 / 小程序 |
| 画面形式 | 2D 还是 3D |
| 游戏类型 | MOBA / 肉鸽 / RPG / 射击 / 塔防 / 格斗… |
| 屏幕适配 | 横屏还是竖屏，目标屏幕比例 |

这四项不必单独占一个问题，可以自然并入相关提问，但**小结中必须有明确结论**。

### 主题 2｜竞品调研与分析

**目标**：搞清「和谁竞争、差异化在哪」，产出完整竞品分析。

1. 先用 1~2 个问题确认用户**最想对标的竞品**与关注点（玩法 / 商业化 / 口碑）。用户没有明确竞品时，基于概念主动检索同类游戏。
2. 用 WebSearch 现场调研这些竞品：玩法循环、评测、商业化、玩家口碑。必要时多轮搜索。
3. 小结必须包含：
   - **逐款竞品拆解**：玩法循环 / 商业模式 / 优点 / 弱点 / 口碑要点
   - **横向对比表**
   - **我们的差异化机会**（3~5 条）
4. **搜索来源注明出处链接**；检索不到或不确定的信息标注「未经核实」，**绝不编造数据**。

> 竞品不预设清单，全部靠实际检索与用户提供。

### 主题 3｜目标用户画像

**目标**：明确「谁在什么设备上、什么场景、玩多久」。

至少覆盖：

- 核心玩家画像（年龄、游戏经历、付费习惯）
- 使用场景（通勤 / 睡前 / 长时段 / 碎片）
- 单次游玩时长预期
- 竞品的用户重叠度

### 主题 4｜核心循环草图

**目标**：把「玩家反复在做什么」写成闭环。

必须说清：

- **重复行为闭环**：玩家做什么 → 得到什么反馈 → 投入什么 → 面对什么更大的挑战
- **单次循环时长**（秒级 / 分钟级 / 小时级）
- **钩子设计**：短期目标、中期目标、长期目标分别是什么

核心循环不成立，后面所有系统设计都是空中楼阁。这一步含糊就追问，不要放过。

### 主题 5｜商业模式

**目标**：明确付费模型与主要付费点（或买断定价逻辑）。

- 付费模型：买断 / F2P + 内购 / 订阅 / 广告变现
- 主要付费点：玩家为什么愿意掏钱
- 付费是否直接影响数值强度，还是只影响外观与便利性

> 这个答案会被 `numeric-balance` 技能用作数值口径的输入，务必问清。

## 产出：一页纸概念案（One-pager）

全部主题完成后汇总为一份文档，结构固定：

```markdown
# 《项目名》一页纸概念案

## 一句话概念
> （电梯陈述：类型 + 题材 + 核心差异点，50 字以内）

## 基本信息
- 类型 / 平台 / 视角 / 目标档期
- 目标用户与核心场景（什么时候、什么设备、玩多久）
- 参考游戏（2~4 款，各自借鉴什么、规避什么）

## 核心循环
- 玩家的重复行为闭环（探索/战斗/经营等 → 反馈 → 投入 → 更大挑战）
- 单次循环时长与钩子设计（短期/中期/长期目标）

## 差异化与卖点
- 3 条核心卖点，每条说明"为什么玩家在意"

## 商业模式
- 付费模型与主要付费点 / 或买断定价逻辑

## 风险与未决问题
- 3~5 条最大的设计或市场风险
```

**约束：**

- 只依据访谈记录中的信息，**不要虚构访谈里没有的决策**
- 访谈未覆盖的部分放进「风险与未决问题」，不要强行编答案
- 直接输出文档本身，不要额外解释

## 自检清单

写完 One-pager 后确认：

- [ ] 一句话概念包含类型 + 题材 + 差异点，50 字以内
- [ ] 四项固定信息（平台 / 2D-3D / 类型 / 横竖屏）有明确结论
- [ ] 核心循环写成了闭环，不是单向流程描述
- [ ] 差异化卖点每条都回答了「为什么玩家在意」
- [ ] 风险与未决问题有 3~5 条真实的，不是「市场风险大」这类空话
- [ ] 全文没有代答痕迹

产物写入 `specs/<project>/01-concept/`（`interview-notes.md` + `one-pager.md`）。
