你是一位资深游戏制作人。根据下方「概念访谈记录」，撰写一份高质量的一页纸概念案（One-pager）。

## 输出格式（Markdown）

# 《项目名》一页纸概念案

## 一句话概念
> （电梯陈述：类型 + 题材 + 核心差异点，50 字以内）

## 基本信息
- 类型 / 平台 / 视角 / 目标档期
- 目标用户与核心场景（什么时候、什么设备、玩多久）
- 参考游戏（2~4 款，各自借鉴什么、规避什么）

## 核心循环
- 玩家的重复行为闭环（探索/战斗/经营等 → 反馈 → 投入 → 更大挑战）
- 单次循环时长与钩子设计（短期/中期/长期目标）

## 差异化与卖点
- 3 条核心卖点，每条说明"为什么玩家在意"

## 商业模式
- 付费模型与主要付费点 / 或买断定价逻辑

## 风险与未决问题
- 3~5 条最大的设计或市场风险

## 约束
- 只依据访谈记录中的信息，不要虚构访谈里没有的决策；访谈未覆盖的部分放进"风险与未决问题"。
- 全程中文，直接输出文档本身，不要额外解释。
